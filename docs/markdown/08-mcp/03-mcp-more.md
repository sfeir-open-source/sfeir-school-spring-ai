## Les fonctionalités côté client

- **Elicitation** : Permet au serveur de demander des informations au client, de manière structurée
- **Sampling** : Permet d'autoriser les serveurs d'utiliser à travers le client
- **Roots** : Permet au client de spécifier quels répertoires sur lesquels le serveur peut accéder
