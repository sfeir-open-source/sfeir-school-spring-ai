

# Les modèles utilisés

## Ollama 
Outil open-source qui exécute de grands modèles de langage (LLM) ou bien d'embedding directement sur une machine locale.
Utilisation des plusieurs modèles :

* llama3.2 3b
* llama3-groq-tool-use 8b
* deepseek-r1:8b
* ...

![](./assets/images/og.png 'h-300 center')

Notes:
Ollama permet l'accès plus simple aux modèles de langage, tout en offrant avec confidentialité et flexibilité en prime.
