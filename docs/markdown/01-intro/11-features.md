

# Principales fonctionnalités
| Fonctionnalité                 | Description                                                                  |
|:-------------------------------|:-----------------------------------------------------------------------------|
| **Support Fournisseurs IA**    | Anthropic, OpenAI, Microsoft, Ollama, Mistral...                             |
| **Support Types de Modèles**   | Text-to-image, chat completion, text-to-speech, modération, embedding        |
| **Functions Calling**/**MCP**  | Capacité à appeler des fonctions externes                                    |
| **Support Bases Vectorielles** | Intégration avec les principales bases de données vectorielles               |
| **ChatClient API**             | API simplifiée pour les interactions de chat                                 |
| **Advisor API**                | API pour la gestion des préoccupations transversales (ex: sécurité, logging) |
| ... |                                                                              |

Notes:

| Fonctionnalité                 | Description                                                               |
|:-------------------------------|:--------------------------------------------------------------------------|
| **Structured Output**          | Formatage structuré des données de sorties (ex: JSON)                     |
| **Observability**              | Suivi et monitoring des interactions IA                                   |
| **Mémoire & RAG**              | Gestion de la mémoire de conversation et *Retrieval-Augmented Generation* |
| **Starters Spring Boot**       | Kits de démarrage pour une intégration facile avec Spring Boot            |
