

# Principales fonctionnalités

* Support des principaux fournisseurs d'IA (Anthropic, OpenAI, Microsoft, Ollama, Mistral...)
* Support des différents type de modèle comme Text to image, chat completion, text to speech, moderation, embedding
* Functions calling
* Structured Output
* Observability
* Support des principaux fournisseurs de base de données vectorielles
* ChatClient API
* Advisor API
* Chat conversation memory and RAG
* Starters spring boot
