# Lab 02 - Je personnalise mon assistant aixolotl
Vous venez de créer un assistant permettant d'échanger avec un modèle de langage, félicitation !
Nous allons maintenant personnaliser notre assistant. En effet, pour l'instant celui-ci ne fait que transmettre le prompt
de notre utilisateur au modèle de langage et renvoie la réponse du modèle tel quel.
Afin d'améliorer ses performances nous allons lui apporter un peu de contexte. 
Notre assistant s'appel aixolotl, son objectif est d'assister un nouvel employé de l'entreprise dans ses démarches 
d'onboarding.

## Structurer notre prompt
Pour rajouter du contexte au prompt transmis par notre nouvel employé nous allons nous appuyer sur l'API Prompts
de SpringAI
https://docs.spring.io/spring-ai/reference/api/chatmodel.html
