# Ollama
Voici le premier exercice de ce labs ! Avant de commencer à explorer Spring AI, 
nous allons d’abord configurer un outil essentiel pour la suite : Ollama. 

Ollama permet d'exécuter des modèles de langage de grande taille (LLM) directement 
sur votre ordinateur. Il simplifie l’utilisation de ces modèles en rassemblant les 
poids du modèle, la configuration et les données dans un seul paquet, défini par un 
Modelfile. 

Cette approche intégrée facilite le déploiement et l'utilisation de 
modèles complexes sur des machines personnelles.

## Installation
Pour accédez au site web et télécharger ollama cliquez ici : [Ollama](https://ollama.com/download)

Une fois installé il vous suffit de vous rendre sur la page de recherce de modèles (https://ollama.com/search)
et choisir celui que vous souhaitez utiliser, et lancer dans un terminal la commande suivante : ```ollama run llama3.2``` (pour llama3.2)

Voilà vous êtes prêt à utiliser Ollama !
